# Mohammad Usman Saud — Portfolio

A personal portfolio site built with Next.js, React Three Fiber, and Framer Motion (`motion`) — featuring an interactive 3D globe in the hero, editorial-style typography, and scroll-driven reveal animations.

## Stack

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **Tailwind CSS v4**
- **React Three Fiber** + **drei** for the interactive 3D scene
- **motion** (Framer Motion) for animation

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Site copy and structured content (experience, projects, skills) live in [`lib/data.ts`](lib/data.ts) — update that file to change what's shown on the page.

## Build

```bash
npm run build
```
